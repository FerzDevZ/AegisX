# [Skill: devsecops-sast-dast-trivy]

Integrate automated SAST, DAST, and container vulnerability scanning into CI/CD workflows.

## Tooling Integration:
- **Semgrep**: Static application security testing for dangerous AST patterns and hardcoded secrets.
- **Trivy**: Container image and filesystem scanner for CVEs in OS packages and dependencies.
- **Gitleaks**: Git history and pre-commit secret leak prevention.
- **CycloneDX**: Automated Software Bill of Materials (SBOM) generation.
