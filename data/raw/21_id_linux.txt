User: Apa perintah Linux dasar yang harus dikuasai pentester?
AegisX: Kuasai dulu navigasi dan file: ls, cd, pwd, cp, mv, rm, mkdir, dan find. Untuk membaca file: cat, less, tail -f untuk log yang terus bertambah, dan head. Untuk teks: grep, sed, awk, dan sort. Untuk proses: ps aux, top atau htop, kill, dan jobs. Untuk jaringan: ip a, ss -tulpn, ping, dan curl. Untuk izin: chmod, chown, dan pahami output ls -l yang menampilkan pemilik, grup, dan mode izin. Untuk pengguna: whoami, id, sudo, dan su. Kuasai juga man untuk dokumentasi dan history untuk melihat perintah sebelumnya. Latihan rutin di terminal Linux adalah cara terbaik untuk hafal, bukan menghafal daftar.

User: Bagaimana cara mencari file dan konten tertentu di Linux?
AegisX: Gunakan find untuk mencari berdasarkan nama, jenis, ukuran, atau waktu: find /home -name "*.conf" mencari file konfigurasi, find / -type f -size +100M mencari file lebih besar dari 100 megabyte. Untuk mencari konten di dalam file, gunakan grep: grep -r "password" /etc mencari teks di semua file, grep -il menampilkan hanya nama file yang cocok tanpa membedakan huruf besar kecil. Kombinasi kuat: grep -rn "api_key" --include="*.py" untuk membatasi jenis file. Untuk pencarian cepat di seluruh sistem, alat seperti ripgrep (rg) jauh lebih cepat daripada grep biasa. Untuk mencari perintah yang pernah dijalankan, gunakan history | grep nama-perintah.

User: Apa itu pipe dan bagaimana menggunakannya di Linux?
AegisX: Pipe dengan simbol | menghubungkan output satu perintah menjadi input perintah berikutnya. Contoh nyata untuk pentest: nmap -sV target | grep open menyaring hasil scan hanya baris yang terbuka. ss -tulpn | grep LISTEN menampilkan hanya port yang sedang mendengarkan. cat /etc/passwd | cut -d: -f1 menampilkan hanya kolom nama pengguna. ps aux | grep nginx mencari proses nginx. Kombinasi dengan sort dan uniq sering dipakai untuk analisis: cat daftar.txt | sort | uniq -c | sort -rn mengurutkan dan menghitung duplikat. Pipeline membuat satu perintah kecil fokus pada satu tugas, lalu dirangkai menjadi alur yang kuat.

User: Bagaimana cara mengelola izin file di Linux?
AegisX: Izin Linux terdiri dari tiga kelompok: pemilik (user), grup (group), dan lainnya (other), masing-masing dengan izin baca (r=4), tulis (w=2), dan eksekusi (x=1). chmod 755 file berarti pemilik bisa baca tulis eksekusi, grup dan lainnya hanya baca eksekusi. chmod 600 file menjadikannya hanya bisa dibaca dan ditulis pemilik, cocok untuk file kunci SSH. chmod +x menjadikan file bisa dieksekusi tanpa mengubah izin lain. chown mengubah pemilik: chown user:group file. Untuk keamanan, prinsipnya beri izin seminimal mungkin. File kredensial sebaiknya 600, direktori pribadi 700, dan skrip yang bisa dieksekusi publik hanya jika benar-benar perlu. File dengan izin world-writable adalah temuan umum pada assessment Linux.

User: Apa itu proses dan bagaimana cara mengelolanya di Linux?
AegisX: Proses adalah program yang sedang berjalan. ps aux menampilkan semua proses dengan pengguna pemilik, penggunaan CPU dan memori, serta perintahnya. Untuk melihat proses tertentu: ps aux | grep nama. top atau htop menampilkan proses secara langsung dan terus diperbarui. Untuk menghentikan proses: kill PID mengirim sinyal berhenti, kill -9 PID memaksa menghentikan proses yang tidak mau berhenti. Saat pentest, perhatikan proses mencurigakan yang berjalan dengan hak istimewa tinggi atau dari direktori aneh seperti /tmp, karena itu indikasi backdoor. Memahami proses penting juga untuk escalation: proses yang berjalan sebagai root dengan kerentanan bisa menjadi target.

User: Apa itu environment variable dan bagaimana menggunakannya?
AegisX: Environment variable adalah nilai yang tersedia untuk semua proses yang berjalan di sesi. PATH menentukan direktori tempat shell mencari perintah, HOME menunjuk direktori rumah, dan variabel kustom sering menyimpan konfigurasi seperti kunci API. Lihat semua dengan env atau printenv. Baca satu: echo $PATH. Set sementara: export KUNCI=nilai berlaku untuk sesi ini, sementara KUNCI=nilai perintah hanya berlaku untuk satu perintah. Penting untuk keamanan: jangan pernah menaruh kredensial di file yang masuk git; pakai environment variable atau file .env yang diabaikan git. Saat pentest web, periksa apakah aplikasi membocorkan environment variable lewat error atau endpoint debug, karena sering berisi rahasia.

User: Apa perbedaan user biasa dan root di Linux?
AegisX: Root adalah pengguna super dengan kendali penuh atas sistem, bisa membaca semua file, mengubah konfigurasi apa pun, dan memasang perangkat lunak. User biasa hanya bisa mengubah file miliknya dan menjalankan perintah tanpa hak sistem. sudo memberi user biasa hak root untuk satu perintah dengan verifikasi kata sandi: sudo apt update. Prinsip keamanan: jangan bekerja sebagai root sepanjang waktu; gunakan user biasa dan sudo hanya saat perlu. Untuk pentest, memahami perbedaan ini penting karena privilege escalation adalah mencari cara mengubah akses user biasa menjadi root, misalnya lewat file sudoers yang salah konfigurasi, binary dengan setuid, atau layanan yang berjalan sebagai root.

User: Apa itu SSH dan bagaimana mengamankannya?
AegisX: SSH adalah protokol untuk login jarak jauh yang aman dengan enkripsi. Koneksi dasar: ssh user@host, dan ssh -p port user@host jika portnya bukan 22. Otentikasi dengan kunci lebih aman daripada kata sandi: buat pasangan kunci dengan ssh-keygen, lalu salin kunci publik ke server dengan ssh-copy-id user@host. Untuk mengamankan server SSH: nonaktifkan login root dengan PermitRootLogin no, nonaktifkan autentikasi kata sandi jika semua klien memakai kunci, ganti port default bukanlah keamanan sejati tapi mengurangi noise serangan otomatis, dan batasi pengguna yang boleh login. Aktifkan fail2ban untuk memblokir alamat yang mencoba brute force. Saat pentest, cek konfigurasi SSH server karena misconfig umum seperti root login aktif atau kata sandi kosong adalah temuan.

User: Bagaimana cara melihat dan menganalisis log di Linux?
AegisX: Log Linux umumnya tersimpan di /var/log. File penting: syslog atau messages untuk pesan sistem, auth.log untuk percobaan login, dmesg untuk pesan kernel, dan log aplikasi di direktori masing-masing. Lihat langsung dengan tail -f /var/log/auth.log untuk memantau percobaan login secara real time. Cari percobaan brute force: grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn menampilkan alamat IP yang paling sering gagal login. journalctl menggantikan log lama di sistem dengan systemd: journalctl -u nama-layanan menampilkan log satu layanan. Saat menangani insiden, log adalah sumber bukti utama, jadi lindungi agar tidak bisa diubah dan kirim ke sistem terpusat.

User: Apa itu shell dan apa bedanya bash dengan sh?
AegisX: Shell adalah antarmuka baris perintah yang menerjemahkan perintah yang kamu ketik menjadi aksi sistem. Bash (Bourne Again Shell) adalah shell default di kebanyakan distribusi Linux dan superset dari sh (Bourne Shell), artinya hampir semua skrip sh berjalan di bash, tetapi bash punya fitur tambahan seperti array, ekspansi brace, dan perintah [[ ]]. Saat menulis skrip, baris pertama menentukan penerjemah: #!/bin/bash atau #!/bin/sh. Untuk pentest, kuasai satu shell dengan baik, lalu pahami perbedaan saat membaca skrip orang lain. Reverse shell sering memakai /bin/bash atau /bin/sh, dan beberapa trik eksploitasi bergantung pada perilaku spesifik shell yang tersedia di sistem target.
