User: Apa itu nmap dan untuk apa digunakan?
AegisX: Nmap adalah alat pemindai jaringan untuk menemukan host yang hidup, port yang terbuka, dan versi layanan yang berjalan. Perintah dasar: nmap -sV target.com untuk deteksi versi layanan, nmap -p- target.com untuk memindai semua 65535 port, dan nmap -sC -sV target.com untuk menjalankan script default dan deteksi versi. Output penting: port 22 untuk SSH, 80 dan 443 untuk web, 3306 untuk MySQL, 5432 untuk PostgreSQL, dan 3389 untuk Remote Desktop. Setelah tahu layanan dan versinya, cocokkan dengan database kerentanan. Ingat: pemindaian aktif menghasilkan lalu lintas ke target, jadi pastikan Anda diizinkan.

User: Apa itu burp suite dan fitur utamanya?
AegisX: Burp Suite adalah alat proxy yang paling banyak dipakai untuk pengujian keamanan web. Fitur utamanya: Proxy untuk mencegat dan memodifikasi permintaan antara browser dan server, Repeater untuk mengirim ulang permintaan dengan modifikasi manual, Intruder untuk serangan otomatis seperti brute force dan fuzzing, Scanner untuk deteksi kerentanan otomatis di versi berbayar, dan Decoder untuk encoding dan decoding payload. Alur kerjanya: set browser Anda lewat proxy Burp, lakukan aktivitas di aplikasi, lalu periksa dan modifikasi permintaan. Komunitas gratisnya sudah cukup untuk belajar dan banyak pengujian manual.

User: Apa itu ffuf dan bagaimana memakainya untuk menemukan direktori?
AegisX: Ffuf adalah fuzzer cepat untuk menemukan direktori, subdomain, parameter, dan nilai tersembunyi. Untuk menemukan direktori: ffuf -w wordlist.txt -u https://target.com/FUZZ. Untuk menemukan subdomain: ffuf -w subdomains.txt -u https://target.com -H "Host: FUZZ.target.com". Gunakan -mc untuk memfilter kode respons yang diinginkan, misalnya -mc 200,301,302, atau -fs untuk menyaring ukuran respons yang sama dengan halaman 404. Wordlist populer: SecLists dari Daniel Miessler. Ffuf sangat cepat karena ditulis dalam bahasa Go, sehingga cocok untuk fuzzing skala besar.

User: Apa itu gobuster?
AegisX: Gobuster adalah alat untuk brute force direktori, file, DNS subdomain, dan virtual host. Perintah dasar untuk direktori: gobuster dir -u https://target.com -w wordlist.txt. Untuk DNS: gobuster dns -d target.com -w subdomains.txt. Untuk virtual host: gobuster vhost -u https://target.com -w wordlist.txt. Kelebihannya sederhana dan stabil; kekurangannya lebih lambat daripada ffuf. Keduanya memakai wordlist yang sama, jadi pilih sesuai preferensi. Hasil yang menarik: file backup, direktori admin, file konfigurasi terpapar, dan endpoint API yang tidak terdokumentasi.

User: Apa itu sqlmap dan kapan menggunakannya?
AegisX: Sqlmap adalah alat otomatis untuk mendeteksi dan mengeksploitasi kerentanan SQL injection. Perintah dasar: sqlmap -u "https://target.com/page?id=1" --dbs untuk mencantumkan database, lalu --tables -D namadb, --columns -T namatabel, dan --dump untuk mengambil data. Ia mendukung banyak teknik: boolean-based, time-based, union, dan error-based. Gunakan sqlmap untuk konfirmasi dan eksploitasi setelah Anda menemukan indikasi SQLi secara manual, misalnya dari perubahan respons saat menyuntikkan tanda kutip. Jangan pernah menjalankannya tanpa izin karena bisa merusak database.

User: Apa itu hydra dan untuk apa?
AegisX: Hydra adalah alat brute force untuk berbagai protokol: SSH, FTP, HTTP form login, SMTP, dan lainnya. Contoh untuk SSH: hydra -l admin -P passwords.txt ssh://target.com. Untuk form login web: hydra -l admin -P passwords.txt target.com http-post-form "/login:username=^USER^&password=^PASS^:Invalid credentials". Hydra menguji kombinasi username dan password secara otomatis. Gunakan dengan hati-hati: serangan brute force menghasilkan banyak log dan bisa memicu rate limiting atau memblokir IP. Pastikan Anda diizinkan menguji target tersebut, dan kombinasikan dengan wordlist yang relevan.

User: Apa itu metasploit?
AegisX: Metasploit adalah framework untuk pengembangan dan eksekusi exploit. Komponen utamanya: msfconsole sebagai antarmuka utama, modul exploit, payload, auxiliary, dan post-exploitation. Alur dasarnya: pilih exploit, atur target dan payload, lalu jalankan. Contoh untuk MS17-010 EternalBlue di Windows: use exploit/windows/smb/ms17_010_eternalblue, set RHOSTS, set PAYLOAD windows/x64/meterpreter/reverse_tcp, set LHOST dan LPORT, lalu exploit. Setelah dapat sesi meterpreter, Anda bisa melakukan post-exploitation seperti mengambil hash, screenshot, atau pindah ke host lain. Gunakan hanya di lab dan target yang diizinkan.

User: Apa itu wireshark?
AegisX: Wireshark adalah penganalisis protokol jaringan yang menangkap dan menampilkan paket yang lewat di jaringan. Fungsinya: melihat lalu lintas HTTP, DNS, dan protokol lain; menemukan percakapan mencurigakan; menganalisis serangan seperti ARP spoofing; dan memeriksa kredensial yang dikirim tidak terenkripsi. Fitur filter sangat berguna, misalnya http.request untuk melihat permintaan HTTP, dns untuk query DNS, atau tcp.port == 443 untuk lalu lintas tertentu. Dalam pentest, Wireshark dipakai untuk memverifikasi bahwa data dikirim terenkripsi atau tidak, dan untuk menganalisis lalu lintas dari malware di lab.

User: Apa itu shodan?
AegisX: Shodan adalah search engine untuk perangkat yang terhubung ke internet. Tidak seperti Google yang mencari halaman web, Shodan memindai port dan mengumpulkan banner layanan, sehingga Anda bisa mencari perangkat dengan kriteria tertentu: server yang menjalankan versi Apache tua, kamera yang terbuka, database yang tidak dilindungi password, atau perangkat IoT. Contoh query: port:22 untuk SSH, product:MySQL untuk server MySQL, atau city:Jakarta untuk perangkat di Jakarta. Dalam pentest, Shodan berguna untuk memahami permukaan serangan organisasi: aset apa saja yang terpapar internet. Ingat, ini untuk pengumpulan informasi pasif dan harus sesuai aturan program.

User: Apa itu theHarvester?
AegisX: Maaf, nama yang benar adalah theHarvester. Alat ini mengumpulkan alamat email, subdomain, host, dan nama dari sumber publik: search engine, PGP servers, dan Certificate Transparency. Contoh perintah: theharvester -d target.com -b all. Hasilnya membantu memahami organisasi: siapa karyawannya, domain apa saja yang terdaftar, dan email format apa yang dipakai. Informasi ini berguna untuk phishing simulation atau menemukan aset yang terlupakan. Ini termasuk passive reconnaissance karena hanya mengambil data publik, tetapi tetap perhatikan kebijakan program dan hukum setempat.

User: Apa itu hashcat?
AegisX: Hashcat adalah alat pemecah hash password dengan memanfaatkan GPU. Ia mendukung banyak algoritma: MD5 dengan mode 0, SHA1 mode 100, bcrypt mode 3200, NTLM mode 1000, dan WPA mode 22000. Dua serangan utama: dictionary attack dengan wordlist, dan mask attack untuk pola tertentu seperti hashcat -m 0 hash.txt -a 3 ?d?d?d?d?d?d untuk PIN 6 digit. Untuk hasil terbaik gunakan GPU dan wordlist yang besar dengan aturan seperti rockyou dan rules dari Hashcat. Kecepatannya sangat bergantung pada algoritma: MD5 bisa miliaran percobaan per detik, sedangkan bcrypt hanya ribuan karena sengaja lambat. Itulah kenapa password harus di-hash dengan algoritma lambat.

User: Apa itu john the ripper?
AegisX: John the Ripper adalah pemecah password yang berjalan di CPU dan mendukung banyak format hash. Perintah dasar: john --wordlist=rockyou.txt hash.txt, dan john --show hash.txt untuk melihat hasil. John otomatis mendeteksi format hash kebanyakan. Ia juga bisa memecah password dari file zip, rar, dan dokumen Office dengan bantuan tool seperti zip2john. Kelebihannya sederhana dan berjalan di mana saja; kekurangannya lebih lambat daripada hashcat di GPU. Untuk lab dan CTF, John adalah pilihan yang bagus karena praktis dan mudah dipakai.

User: Apa itu dirb dan dirsearch?
AegisX: Dirb adalah pemindai direktori klasik: dirb https://target.com. Dirsearch adalah pengganti yang lebih cepat dan banyak dipakai: dirsearch -u https://target.com -e php,html,bak. Keduanya memakai wordlist dan menemukan path tersembunyi seperti /admin, /backup, /config, dan file dengan ekstensi sensitif. Hasil yang menarik biasanya: file backup .bak, file .git terpapar, panel admin tanpa proteksi, dan endpoint API. Meskipun ffuf lebih cepat, dirb dan dirsearch tetap berguna karena sederhana dan hasilnya mudah dibaca. Jangan lupa periksa robots.txt juga, meskipun kadang sengaja disembunyikan di sana.

User: Apa itu wappalyzer?
AegisX: Wappalyzer adalah ekstensi browser dan alat yang mendeteksi teknologi yang dipakai sebuah situs: framework (React, Vue, Laravel), server (nginx, Apache), CMS (WordPress), analitik, dan lainnya. Dalam pentest, informasi ini berguna untuk memperkirakan kerentanan: situs WordPress versi lama berarti plugin-nya perlu dicek, situs Laravel berarti perlu melihat konfigurasi dan debug mode. Wappalyzer juga tersedia sebagai API untuk pemindaian otomatis. Ini langkah pertama yang cepat untuk memahami tumpukan teknologi target sebelum pengujian lebih dalam. Ingat, deteksi teknologi bukan temuan, tetapi peta jalan untuk mencari kerentanan yang relevan.

User: Apa itu nuclei?
AegisX: Nuclei adalah pemindai kerentanan berbasis template dari ProjectDiscovery. Ia menjalankan ribuan template untuk berbagai kerentanan: CVE tertentu, misconfiguration, exposed panels, dan teknologi spesifik. Contoh perintah: nuclei -u https://target.com -t cves/ untuk memindai CVE, atau nuclei -l hosts.txt -t exposures/ untuk memindai banyak host. Kelebihannya cepat, mudah diperbarui (nuclei -update-templates), dan sangat fleksibel karena template berbasis YAML. Nuclei biasanya dipakai setelah menemukan host dan teknologi, sebagai langkah pemindaian luas sebelum pengujian manual. Kombinasikan dengan httpx untuk memfilter host yang hidup dulu.

User: Apa itu httpx?
AegisX: Httpx dari ProjectDiscovery adalah alat untuk memeriksa host yang hidup dan mengambil informasi dasar dari banyak target sekaligus: kode status, judul halaman, server, teknologi, redirect, dan sertifikat TLS. Contoh: cat hosts.txt | httpx -title -status-code -tech-detect -follow-redirects. Alur khas: subfinder untuk menemukan subdomain, lalu httpx untuk menyaring mana yang live, lalu nuclei atau pengujian manual pada yang live. Ini menghemat waktu besar karena dari ratusan subdomain biasanya hanya puluhan yang hidup. Outputnya bisa langsung disalurkan ke alat lain dengan pipa.

User: Apa itu gobuster vhost dan bedanya dengan subdomain?
AegisX: Virtual host (vhost) berbeda dengan subdomain. Subdomain adalah nama DNS yang nyata, misalnya api.target.com. Virtual host adalah beberapa situs yang berbagi satu alamat IP dan dibedakan oleh header Host, misalnya staging.target.com dan dev.target.com yang keduanya menunjuk ke IP yang sama tetapi menampilkan situs berbeda. Gobuster vhost mencoba menemukan vhost tersembunyi: gobuster vhost -u https://target.com -w wordlist.txt. Ini penting karena banyak organisasi menyimpan aplikasi internal di vhost yang tidak terdaftar di DNS, sehingga tidak ditemukan oleh enumerasi subdomain biasa tetapi bisa diakses jika Anda tahu nama hostnya.

User: Apa itu mimikatz?
AegisX: Mimikatz adalah alat post-exploitation di Windows yang terkenal untuk mengambil kredensial dari memori: password plaintext, hash, dan Kerberos tickets. Perintah terkenalnya: sekurlsa::logonpasswords untuk mengambil kredensial dari proses LSASS, dan sekurlsa::kerberos untuk ticket. Mimikatz sering dipakai setelah mendapatkan akses awal di Windows, misalnya lewat meterpreter: load mimikatz lalu kerberos atau lsadump. Ini alat yang sangat kuat tetapi juga berbahaya: hanya gunakan di lab dan lingkungan yang Anda miliki. Banyak EDR mendeteksi Mimikatz, jadi teknik modern lebih banyak memakai versi alternatif atau mengekstrak memori LSASS secara langsung.

User: Apa itu bloodhound?
AegisX: BloodHound adalah alat untuk memetakan dan menganalisis Active Directory dengan teori graf. Ia mengumpulkan data hubungan antara pengguna, grup, komputer, dan sesi, lalu menampilkannya sebagai graf yang menunjukkan jalur serangan: siapa yang bisa mencapai admin domain dengan kombinasi langkah apa. Alurnya: jalankan SharpHound atau BloodHound collector di domain, upload hasilnya ke BloodHound UI, lalu analisis grafnya. Ini sangat berguna dalam pentest Active Directory karena menampilkan jalur privilege escalation yang tidak terlihat. Temuan khas: pengguna biasa yang anggotanya grup admin lokal di mesin tempat admin domain login, atau izin GenericAll pada grup penting.

User: Apa itu responder?
AegisX: Responder adalah alat untuk menangkap kredensial di jaringan dengan menjawab permintaan autentikasi LLMNR, NBT-NS, dan mDNS yang gagal di lingkungan Windows. Ketika ada host yang mencoba menyelesaikan nama yang tidak dikenal, Responder berpura-pura menjadi host tersebut dan meminta autentikasi, lalu menangkap hash NetNTLMv2. Hash itu kemudian bisa dipecah offline atau digunakan untuk serangan relay. Ini adalah teknik klasik dalam pentest internal. Pencegahannya: nonaktifkan LLMNR dan NBT-NS di lingkungan, aktifkan SMB signing, dan gunakan autentikasi yang lebih kuat. Responder hanya efektif di jaringan di mana protokol lama masih aktif.
