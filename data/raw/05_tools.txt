Penetration testing tools turn methodology into action. Every serious tester has a toolkit, but tools are only as good as the person running them. Learn one tool deeply before adding the next. The core toolkit covers reconnaissance, scanning, exploitation, and reporting.

Nmap is the standard network scanner. The syntax is nmap followed by targets and options. Scan a single host with nmap 192.168.1.10. Scan a range with nmap 192.168.1.0/24. The -sV flag enables version detection, which fingerprints the exact software version running on each open port. The -p flag selects ports, like -p 22,80,443 or -p- for all 65535 ports. The -Pn flag skips host discovery and treats every host as alive, which helps when ICMP is blocked. Output formats matter for reporting: -oN saves normal output, -oX saves XML for tools like Metasploit, and -oG saves greppable output for scripts.

Nuclei is a fast vulnerability scanner driven by templates. Instead of writing checks by hand, you run thousands of community-contributed templates against a target. The command nuclei -u https://example.com scans a single URL, while nuclei -l targets.txt scans a list. The -severity flag filters results by severity, like -severity high,critical. Templates detect everything from exposed configuration files to known CVEs in specific software versions. Because templates are YAML files, you can write your own checks for custom findings.

Ffuf is a web content discovery tool written in Go. It fuzzes directories, files, parameters, and virtual hosts using wordlists. The basic directory brute force uses ffuf -u https://example.com/FUZZ -w wordlist.txt. The FUZZ keyword marks where each wordlist entry gets inserted. Filter results with -mc for matching status codes or -fc for filtering them out. Always filter false positives: match only codes that indicate real content like 200, 204, 301, 302, or 403, and filter by response size with -fs when a known baseline exists.

Gobuster works like ffuf but focuses on directories, DNS subdomains, and virtual hosts. Directory brute forcing finds hidden paths, while DNS mode discovers subdomains by brute forcing names against a DNS server. Virtual host discovery sends requests with different Host headers to find vhosts that resolve to the same IP. Wordlist quality drives results: the SecLists project by Daniel Miessler contains curated wordlists for every purpose, from common passwords to directory names to API endpoints.

Burp Suite is the standard tool for web application testing. The proxy intercepts traffic between the browser and the target, letting you modify requests before they are sent. The repeater sends modified requests repeatedly, the intruder automates payload injection for fuzzing, and the scanner automates vulnerability detection. The extension system adds power: extensions like the Autorize plugin detect authorization flaws automatically. Burp Community is free but lacks the scanner; the professional version adds the scanner and more automation.

Sqlmap automates SQL injection detection and exploitation. It takes a URL with a parameter and tests it against dozens of injection techniques. The command sqlmap -u "https://example.com/page?id=1" tests the id parameter. Add --dbs to enumerate databases, -D dbname --tables to list tables, and -D dbname -T tablename --dump to extract data. Sqlmap supports boolean-based, time-based, error-based, union-based, and stacked queries. Always run sqlmap against authorized targets only; it sends thousands of requests and is very noisy.

Metasploit is an exploitation framework with thousands of modules. The console starts with msfconsole. Search modules with the search command, like search apache. Select a module with use, set its options with set RHOSTS and set LHOST, and launch it with exploit or run. Meterpreter is the post-exploitation payload that runs inside a compromised host and provides file system access, screenshots, keylogging, and pivoting. The auxiliary modules perform scanning and enumeration without exploitation. Metasploit pairs naturally with nmap output: import scan results and match them to exploits.

Network traffic analysis tools reveal what crosses the wire. Wireshark captures and inspects packets with a graphical interface, while tcpdump does the same from the command line. Capture on an interface with tcpdump -i eth0, filter by host with host 192.168.1.10, or by port with port 443. Following TCP streams in Wireshark reassembles conversations so you can read the actual data exchanged. Understanding protocols at the packet level makes you a better tester because you see exactly what the application sends and receives.

Post-exploitation tools extend access after a successful compromise. Linpeas and WinPEAS enumerate privilege escalation paths on Linux and Windows. They check for misconfigured sudo, world-writable scripts, credentials in files, and outdated software with known local exploits. The enumeration output guides the escalation attempt: find a weakness, exploit it, and repeat until you reach root or SYSTEM. BloodHound maps Active Directory relationships to find attack paths, showing which users can reach which targets through group memberships.

Password attacks test the authentication boundary. Hydra brute forces network services with username and password lists, while hashcat cracks captured hashes on GPU. John the Ripper also cracks hashes with CPU. The quality of wordlists and rules determines success: standard lists like rockyou.txt cover common passwords, while mangling rules generate variations. Online brute forcing is slow and noisy, so harvest hashes offline whenever possible and crack them locally. Always respect account lockout policies during authorized tests.

Reporting tools close the loop. Templates in markdown or Word document structured findings consistently. Every finding needs a title, severity, affected asset, description, reproduction steps, impact, and remediation. Screenshots prove the finding and speed up triage. Automated scanners produce raw output, but a human must interpret it: scanners generate false positives, and the report should only include verified findings with business impact clearly stated.
