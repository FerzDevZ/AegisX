User: Apa itu CTF dan bagaimana cara memulainya?
AegisX: CTF atau Capture The Flag adalah kompetisi keamanan siber di mana peserta memecahkan tantangan untuk mendapatkan flag, yaitu string unik seperti AEGISX{contoh_flag}, sebagai bukti berhasil. Format umum ada dua: jeopardy, di mana tantangan tersusun dalam kategori dengan tingkat kesulitan dan nilai poin, dan attack-defense, di mana tim menyerang sistem tim lain sambil mempertahankan sistem sendiri. Untuk pemula, mulai dengan format jeopardy di platform seperti picoCTF, CTFlearn, dan HackTheBox. Kuasai satu kategori dulu, biasanya web atau kriptografi, lalu pelajari sisanya. Yang terpenting: dokumentasikan setiap solusi karena trik yang sama muncul berulang di tantangan lain.

User: Apa saja kategori tantangan di CTF?
AegisX: Kategori utama CTF: web exploitation untuk kerentanan aplikasi web seperti SQL injection dan XSS, cryptography untuk memecahkan sandi dan memanfaatkan kelemahan implementasi, reverse engineering untuk menganalisis program biner dan menemukan logika tersembunyi, pwn atau binary exploitation untuk mengeksploitasi kerentanan memori, forensics untuk menganalisis file, gambar, dan lalu lintas jaringan, OSINT untuk mencari informasi dari sumber publik, dan miscellaneous untuk tantangan yang tidak masuk kategori lain seperti game dan steganografi. Setiap kategori melatih keterampilan berbeda, dan sebagian besar pemain mengembangkan spesialisasi di satu atau dua kategori sambil tetap memahami dasar kategori lain.

User: Bagaimana cara menyelesaikan tantangan kriptografi di CTF?
AegisX: Mulai dengan mengidentifikasi jenis sandi dari bentuknya. Teks yang hanya berisi huruf bisa sandi Caesar, Vigenere, atau substitution. Deretan angka atau karakter aneh bisa base64, hex, atau binary. Identifikasi pola: base64 selalu berakhiran = jika panjangnya kelipatan tiga, hex hanya berisi 0-9 dan a-f. Untuk sandi klasik, alat seperti CyberChef dan dcode.fr bisa mendeteksi dan memecahkan otomatis. Perhatikan judul dan deskripsi tantangan karena sering memberi petunjuk jenis sandi. Untuk kriptografi modern, cari kelemahan implementasi: penggunaan kunci yang sama berulang, nonce yang dipakai ulang, atau modulus RSA yang bisa difaktorkan. Alat penting: CyberChef, RsaCtfTool, dan SageMath untuk perhitungan matematika.

User: Bagaimana cara menyelesaikan tantangan web di CTF?
AegisX: Mulai dengan inspeksi menyeluruh: buka halaman, lihat sumber HTML, periksa file JavaScript, dan coba endpoint yang tersembunyi. Perhatikan cookie karena flag kadang ada di dalamnya atau izin bisa diubah lewat cookie. Uji kerentanan umum sesuai konteks: SQL injection di form login, XSS di kolom input, dan path traversal di parameter file. Di CTF, kerentanan sering dibuat sederhana dan disengaja, jadi perhatikan komentar di kode, halaman yang tidak tertaut, dan perilaku yang aneh. Gunakan alat seperti Burp Suite untuk memanipulasi permintaan dan ffuf untuk menemukan direktori tersembunyi. Jika menemukan source code, baca dengan teliti karena flag sering tersembunyi di logika yang tampaknya tidak berbahaya.

User: Bagaimana cara menyelesaikan tantangan reverse engineering di CTF?
AegisX: Reverse engineering adalah menganalisis program untuk memahami cara kerjanya tanpa source code. Mulai dengan alat statis: file untuk mengetahui jenis biner, strings untuk melihat string yang bisa dibaca, dan objdump atau Ghidra untuk menganalisis kode assembly. Cari perbandingan yang mencurigakan: program biasanya membandingkan input dengan flag, jadi cari fungsi yang memproses input dan perbandingan string. Gunakan debugger dinamis seperti gdb untuk menjalankan program langkah demi langkah dan mengamati nilai register serta memori. Di CTF, flag sering diperiksa karakter per karakter, jadi pendekatan umum adalah menambal instruksi perbandingan agar selalu benar, atau memanggil fungsi pemeriksa langsung. Ghidra gratis dan sangat membantu untuk pemula karena menerjemahkan assembly ke pseudo-code C.

User: Apa itu pwn dan binary exploitation di CTF?
AegisX: Pwn adalah kategori mengeksploitasi kerentanan di program biner, biasanya kerentanan memori. Tantangan umum: buffer overflow di mana input melebihi buffer dan menimpa data di sekitarnya, format string vulnerability yang memungkinkan membaca atau menulis memori lewat format yang salah, dan use-after-free. Tujuannya sering mendapatkan shell atau membaca flag yang tersimpan di memori. Untuk menyelesaikannya kamu perlu memahami memori proses, stack, heap, dan mekanisme perlindungan seperti ASLR, NX, dan stack canary. Alat penting: checksec untuk melihat perlindungan yang aktif, pwntools untuk menulis eksploitasi dengan Python, dan gdb dengan plugin seperti pwndbg. Mulai dari tantangan tanpa perlindungan untuk memahami dasarnya, lalu pelajari bypass satu per satu.

User: Bagaimana cara menyelesaikan tantangan forensik di CTF?
AegisX: Forensik di CTF biasanya memberi file yang menyembunyikan informasi: gambar dengan data tersembunyi, file dengan banyak lapisan, atau tangkapan lalu lintas jaringan. Mulai dengan mengidentifikasi file: file nama_file dan periksa tanda tangan file di awal dengan hexdump, karena ekstensi bisa salah. Untuk gambar, cek steganografi: strings untuk string tersembunyi, binwalk untuk file yang menempel, dan zsteg untuk gambar PNG dan BMP. Untuk file zip yang terkunci, coba kata sandi umum atau crack dengan john. Untuk tangkapan jaringan pcap, buka dengan Wireshark dan ikuti aliran TCP untuk melihat percakapan, cari file yang dikirim lewat http dengan export objects. Metadata file juga bisa menyembunyikan informasi, periksa dengan exiftool. Kunci forensik: jangan percaya ekstensi dan periksa semuanya.

User: Apa itu OSINT challenge di CTF?
AegisX: OSINT atau Open Source Intelligence adalah mencari informasi dari sumber publik. Di CTF, tantangan OSINT bisa memintamu menemukan lokasi dari foto, mencari akun media sosial seseorang, atau melacak informasi dari metadata. Teknik umum: reverse image search dengan Google Lens atau Yandex, mencari nama atau handle di berbagai platform, memeriksa metadata foto dengan exiftool yang bisa berisi lokasi GPS, dan mencari arsip halaman dengan Wayback Machine. Geolokasi foto adalah keterampilan inti: perhatikan rambu, bahasa, tanaman, arsitektur, dan pemandangan khas. Tantangan OSINT melatih ketelitian dan pencarian kreatif, dan keterampilan ini sangat berguna juga untuk reconnaissance di dunia nyata.

User: Apa itu steganografi dan bagaimana cara mendeteksinya?
AegisX: Steganografi adalah menyembunyikan pesan di dalam media lain sehingga keberadaannya tidak terlihat, berbeda dengan kriptografi yang membuat pesan tidak bisa dibaca tetapi tetap terlihat. Di CTF, pesan sering disembunyikan di gambar dengan menyisipkan data di bit rendah piksel (LSB), di file audio dengan spektogram, atau dengan menempelkan file di belakang file lain. Cara mendeteksi: periksa ukuran file yang tidak wajar untuk jenisnya, jalankan strings dan binwalk, bandingkan bit rendah gambar dengan alat seperti zsteg, dan lihat spektrum audio dengan Sonic Visualiser atau Audacity. Jika menemukan data yang tampak terenkripsi setelah diekstrak, itu sering menjadi tantangan kriptografi berikutnya. Steganografi juga dipakai penyerang sungguhan untuk menyembunyikan muatan malware.

User: Bagaimana cara bekerja sama dalam tim CTF?
AegisX: Kerja tim yang baik dimulai dengan pembagian peran sesuai kekuatan: satu orang fokus web, satu pwn, satu reverse, dan seterusnya. Buat saluran komunikasi terpisah untuk setiap kategori agar pembahasan tidak tercampur. Gunakan papan bersama untuk melacak tantangan yang sedang dikerjakan, yang sudah selesai, dan petunjuk yang ditemukan. Dokumentasikan setiap solusi segera setelah berhasil, termasuk langkah dan flag, karena di akhir kompetisi nilai laporan bisa dihitung dan solusi bisa dipakai ulang. Jangan diam terlalu lama di satu tantangan; jika macam lebih dari 30 menit, minta bantuan atau pindah ke tantangan lain. Bagikan temuan kecil seperti kata sandi umum atau teknik baru ke seluruh tim. Komunikasi yang rapi sering mengalahkan kemampuan individu.

User: Apa yang harus dipelajari pemula sebelum ikut CTF?
AegisX: Bangun fondasi dulu: pahami cara kerja web, HTTP, HTML, dan JavaScript untuk kategori web; dasar Python untuk menulis skrip bantu; perintah Linux dasar; dan konsep jaringan seperti port dan protokol. Pelajari representasi data: hex, biner, base64, dan ASCII karena muncul di mana-mana. Selesaikan picoCTF yang dirancang untuk pemula dengan petunjuk berjenjang, dan baca writeup peserta lain setelah mencoba sendiri. Bergabung dengan komunitas dan platform latihan seperti picoCTF, CTFlearn, dan OverTheWire untuk Linux. Aturan penting: kerjakan tantangan secara mandiri dulu sebelum membaca writeup, karena kemampuan memecahkan masalah adalah keterampilan yang paling dilatih CTF. Konsistensi latihan kecil setiap hari lebih baik daripada belajar maraton sesekali.
